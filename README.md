# Wasserschwein — робот для физического «Арканоида»

Wasserschwein — это система, в которой камера сверху видит мяч и каретку
робота, а компьютер отправляет каретке команды движения. Raspberry Pi Pico
принимает эти команды по Bluetooth и управляет мотором. Цель — подвезти каретку
к месту, где мяч пересечёт её линию.

Это не обязательный проект с нейросетью: в обычной работе программа выделяет
мяч и метку робота по цвету. Это проще, быстрее и легче проверять. Нейросеть
YOLO оставлена только как отдельный эксперимент.

## Начните отсюда

Полное пошаговое руководство — от установки программ до проверки настоящего
робота — находится в [docs/PROJECT_GUIDE_RU.md](docs/PROJECT_GUIDE_RU.md).
Оно написано для человека, который не обязан знать ни машинное обучение, ни
фильтр Калмана.

Подробный разбор каждой функции, алгоритмов и возможных альтернатив находится
в [docs/CODE_AND_ALGORITHMS_RU.md](docs/CODE_AND_ALGORITHMS_RU.md).

Краткая безопасная последовательность для компьютерной части:

```bash
git clone https://github.com/Kirill-DoS/wasserschwein.git
cd wasserschwein
cp .env.example .env
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -v
```

Затем заполните `.env`, подключите камеру и Bluetooth-модуль, проведите
разметку поля и запустите:

```bash
python3 -m vision.main
```

## Самое важное о настройках

Все изменяемые настройки находятся в одном файле `.env` в корне репозитория:

- камера и Bluetooth;
- размеры поля и цветовые диапазоны;
- скорость и плавность движения каретки;
- параметры прошивки Pico, включая пины и таймер безопасности.

Файл `.env` не попадает в Git, потому что содержит настройки конкретного
стенда. В репозитории хранится только безопасный шаблон
[.env.example](.env.example). Не меняйте значения пинов и ESC, пока не
проверите схему и не прочитаете соответствующий раздел подробного руководства.

## Структура

```text
vision/        Компьютерное зрение, прогноз мяча и управление роботом
firmware/      Прошивка Raspberry Pi Pico и сборка файла .uf2
hardware/      Модели деталей и конструкторские материалы
tools/         Отдельные диагностические и учебные утилиты
tests/         Автоматические проверки без камеры и робота
docs/          Подробное руководство и правила поля
```

## Частые команды

| Задача | Команда из корня репозитория |
| --- | --- |
| Установить зависимости | `python3 -m pip install -r requirements.txt` |
| Запустить автоматические тесты | `python3 -m unittest discover -s tests -v` |
| Найти номер камеры | `python3 tools/camera_index.py` |
| Ручной стоп робота | `python3 -m vision.bluetooth_cli S` |
| Запустить игру | `python3 -m vision.main` |
| Собрать прошивку Pico | `make -C firmware all` |

## Безопасность

- Первые тесты выполняйте с поднятыми колёсами либо на минимальной мощности.
- Держите кнопку остановки и отключение питания в пределах руки.
- Закрытие программы, потеря мяча или метки робота отправляют команду `S`.
- Pico самостоятельно останавливает каретку, если новые команды не приходят
  дольше времени `PICO_COMMAND_TIMEOUT_MS` из `.env`.

Подробный порядок проверки и диагностики неисправностей — в
[руководстве](docs/PROJECT_GUIDE_RU.md).
