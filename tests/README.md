# Автоматические тесты

Эта папка содержит проверки, которые запускаются без камеры, Bluetooth,
Raspberry Pi Pico, моторов и интернета. Они проверяют небольшие части логики и
помогают заметить ошибку до включения настоящего робота.

Запускайте из корня проекта:

```bash
source .venv/bin/activate
python3 -m unittest discover -s tests -v
```

Успешный итог выглядит так:

```text
----------------------------------------------------------------------
Ran ... tests in ...s

OK
```

Сейчас проверяется `vision.robot_controller`:

- рядом с целью действует мёртвая зона: мотор не должен постоянно менять
  направление;
- скорость меняется плавно, с ограничением ускорения;
- мощность PWM не выходит за допустимый диапазон;
- аварийный сброс очищает старую команду движения.

Также проверяется `.env.example`: генератор должен получить из него все
обязательные параметры Pico и создать временный заголовок C.

Эти проверки не заменяют испытание железа. После успешных тестов всё равно
проверьте ручный стоп, малую мощность, потерю Bluetooth и потерю мяча — порядок
описан в [полном руководстве](../docs/PROJECT_GUIDE_RU.md).
